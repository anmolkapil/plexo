Privacy

The Plexo app

Last updated: November 6, 2026

Plexo sends anonymous stats to help fix problems: the app version, your system, and whether downloads finish or why they fail. It never sends links, file names or your IP address. You can turn them off at any time.

When stats are sent

Stats are on unless you turn them off. Plexo tells you about them the first time you open it, and nothing is sent until you click OK on that notice or it has been on screen for a minute. Stats are collected in memory and sent about every 15 minutes, and when Plexo quits. If your computer is offline they are dropped, never saved for later. At most 200 events a day are sent.

Plexo sends nothing if the DO_NOT_TRACK environment variable is set, and builds you make yourself from the source code never send stats.

What every batch includes

A random install ID
Made for these stats alone, and not taken from your computer, accounts or hardware. Turning stats off deletes it; turning them back on makes a new one.
App version, operating system and its major version, and processor type
For example 1.0.0, win32, 11, x64.
Language
The language your system uses, for example zh-CN, to decide which translations to add.

The events

Event What it contains
app_start How many networks of each kind the computer has (Wi-Fi, Ethernet, USB, bridge, other), whether the browser extension has been used, and whether automatic updates are on.
download_finished The kind of download (web, torrent, Usenet, Telegram), its size, how long it took and its average speed, each as a range such as 100MB-1GB, and the kinds of network that downloaded part of it.
download_failed The kind of download, a short code for why it failed (such as dns, no_space or http_403, never the error's own text), the server's status code if it gave one, how much had downloaded as a range, and the kinds of network used.
app_error An error Plexo didn't handle: which part of the app it happened in, the error's type (such as TypeError), a short code, and up to five places in Plexo's own code, as file name and line number. Never the error's message.
process_gone Part of the app stopped unexpectedly: which part, the reason and the exit code.
update_failed A short code for why an update failed.

What is never sent

  • Links, website or server names, or any part of a link
  • File and folder names, torrent names, magnet links or hashes
  • Cookies, sign-in details, proxy settings or network names
  • Your IP address or any local address
  • Exact file sizes, or when exactly you downloaded something
  • Anything you type into Plexo

The server that receives the stats checks every event against the list above and drops anything that doesn't match. It doesn't store the IP address the request came from. Stats are kept for three months.

Turning stats off

Click Turn off on the notice, or open the networks menu, choose Speed & data limits, and switch off Anonymous stats. Anything not yet sent is dropped, and the install ID is deleted.

The source

Plexo is open source. The list of events is in src/shared/stats.ts, and the server that receives them is in stats-worker/. Any change to what is sent changes this page too.
