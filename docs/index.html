      Use separate connections

      Plexo is faster only when each network has its own Internet line, like home Wi-Fi plus a phone on USB tethering. Two connections to the same router share one line, so they won't add speed.

      USB tethering on macOS

      Macs don't recognize an Android phone's USB tethering out of the box — you'll need a free helper app called TetherKit first.

      1. Install TetherKit: open Terminal and run brew install XiaoMiku01/tap/tetherkit
      2. Connect your Android phone to your Mac with a USB cable.
      3. On your phone: Settings → Network & Internet → Hotspot & tethering → turn on USB tethering.
      4. Open Plexo — it'll pick up the connection automatically.

      Full guide on GitHub →

      Wi-Fi keeps dropping?

      Some Windows 10/11 PCs switch off Wi-Fi as soon as an Ethernet cable is connected. To stop that:

      1. Press Win + R, type gpedit.msc, and press Enter.
      2. Go to Computer Configuration → Administrative Templates → Network → Windows Connection Manager.
      3. Set “Minimize the number of simultaneous connections to the Internet or a Windows domain” to Disabled.
