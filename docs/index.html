FAQ

Questions, answered

How does Plexo combine my connections?+

Plexo splits a download into smaller chunks, downloads those chunks over all the connections you've selected, then puts them back together as one file. This lets one download use the combined capacity of your available connections.

Which connections can I combine?+

You can combine active connections available on your computer, such as Wi-Fi, Ethernet, and a phone connected through USB tethering. Each connection needs to provide a separate route to the internet.

Why does my computer warn me when I open Plexo?+

Plexo isn't code-signed yet, so macOS and Windows may show a security warning the first time you open it. Follow the first-launch steps under Downloads for your system. You only need to do this once, and the full source code is available on GitHub. Code-signing licenses cost money; if you'd like to help remove these warnings, consider sponsoring Plexo so the project can cover them.

Can Plexo combine internet speed for my whole device?+

No. Plexo combines connections only for downloads started inside Plexo. It isn't a VPN and doesn't change how browsers, games, streaming apps, or other software use the internet.

Is Plexo stable?+

Plexo is currently a pre-release. The core download flow works, but you may still encounter bugs or rough edges. If something goes wrong, please report it on GitHub.

How do I use Android USB tethering on a Mac?+

macOS doesn't support Android USB tethering by itself. Install TetherKit, connect your phone by USB, then turn on USB tethering in your phone's hotspot and tethering settings. Once macOS shows it as a network connection, Plexo can use it. Follow the full Android USB tethering tutorial.
